# 小说起名与姓名查重工具

人物、帮派、武功、地点和兵器起名，以及晋江优先的实时姓名查重。

在线工具：https://novel-name-studio.comet-frog-6168.chatgpt.site/

## 功能

- 年代、性别、姓氏、字数与命名套路筛选；含小名和乡土朴实名。
- 内置分类名字样例和意象组合，最近生成的名字在浏览器中避重。
- 晋江主角标签完全同名核对，展示收藏、文章积分、字数、进度及来源可提供的日期。
- 自动核对前五页，继续下滑逐页追加；网络同名和公众人物线索独立检索。
- 起名收藏、查询记录、可接受标记、候选对比及 JSON 备份。

## 本地运行

需要 Node.js 22.13 或更高版本、pnpm。

```sh
pnpm install
pnpm dev
```

构建和检查：

```sh
pnpm exec tsc --noEmit
pnpm build
```

项目使用 React、Vinext、Vite，保留 Cloudflare Worker / Sites 的构建集成。默认开发端口为 5173，实际地址以终端输出为准。

## 代码位置

- `app/name-generator.tsx`：起名区界面。
- `lib/names.ts`、`lib/name-data.ts`：素材与组合规则。
- `app/page.tsx`：查询、自动分页、本地记录及结果界面。
- `app/api/search/route.ts`：晋江流式查询。
- `app/api/web/route.ts`、`lib/progressive.ts`：网络检索。
- `lib/search.ts`：来源读取、编码与页面解析。

## 数据说明

起名使用工具内整理的样例、姓氏、常见用字和组合规则，不取用晋江角色库；年代为写作风格参考，非人口姓名统计。晋江与网络用于查重。

搜索结果仅覆盖本次已读取范围，未命中不代表名字唯一。网络及公众人物结果为需核对的索引线索，不作为未经证实的禁用名单。完结日期只展示来源明确提供的日期，不能用最后更新时间代替。

收藏与历史记录保存在当前浏览器；外部来源可能因限流、验证、页面变动或网络问题读取失败。
